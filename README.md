# Textbook Finder

Textbook Finder helps users locate legitimately accessible learning materials and open educational resources.

## Permitted Use

You may use this project to:

- Discover resources that are openly licensed (for example, OER, Creative Commons, open access, and public domain).
- Access/download material only when you have legal rights, institutional permission, or another valid authorization.
- Support course planning, library discovery, and scholarship workflows that comply with copyright law.
- Comply with campus, district, or organizational acceptable-use and IT policies when searching from institutional networks.

## Prohibited Use

You may **not** use this project to:

- Circumvent paywalls, DRM, authentication systems, or publisher controls.
- Locate or distribute pirated, unauthorized, or infringing copies of copyrighted materials.
- Violate campus policy, computer misuse policy, or local/state/federal law.
- Automate abusive requests against third-party services or repositories.

## Policy Attestation

Before searching, users must attest to the following statement:

> I have rights or permission to access/download this material.

The app records policy version and acceptance timestamp for auditability in local library metadata.
